# MidnightBrew

A premium, minimalist survival dashboard for **Brewmaster Monks** in World of Warcraft: Midnight (**Patch 12.0.5**).

## Features
- **EHP Master Bar:** A consolidated health indicator that accounts for Stagger and Celestial Brew shields.
- **Shado-Pan Intelligence:** Automated tracking of the **Predictive Training** (8% DR) window.
- **M+ Sentinel:** Automatic marking of dangerous mobs and interrupt announcements.
- **Statue Watcher:** Real-time health and uptime monitoring for your Black Ox Statue.
- **Intelligent Fading:** The UI snaps into focus when you enter combat and fades out when exploring.
- **Diagnostic Engine:** Built-in persistent logging and snapshots for easy troubleshooting.

## Installation
1. Download this repository.
2. Place the `MidnightBrew` folder in your `_retail_/Interface/AddOns/` directory.
3. Use `/mb` in-game to see available commands.

## Philosophy
This addon is designed for players who focus on **staying alive and executing clean pulls**. It removes visual clutter and highlights only the most critical survival information.
